# Healthcare Lab v1.2.0

## Highlights

### DICOM ECG Viewer

- Parse and normalize both supported DICOM ECG waveform storage formats.
- Retrieve reconciled ECG instances safely through application-owned WADO-RS
  APIs.
- Render deterministic 12-lead ECG SVG graphs without relying on Streamlit.
- Add a dedicated ECG viewer to the patient-centered dcm4chee result workflow.
- Add end-to-end verification and safe synthetic ECG fixtures.

Related: ZAC-92, ZAC-93, ZAC-94, ZAC-95, and ZAC-96.

### GDT Host Folder Configuration

- Add a bounded host-path controller for Windows deployments.
- Allow operators to configure the GDT host folder from the Healthcare Lab
  console.
- Apply validated path changes through a controlled container recreation
  workflow.

## Improvements

- Standardize FHIR order identifiers as six-digit values.
- Improve OIE and Medplum settings behavior.
- Refresh the README, workflow overview, contribution guide, security policy,
  issue templates, and pull-request template.
- Add a reproducible GitHub social-preview generator.
- Update the default Healthcare Lab container image to `1.2.0`.

## Fixes

- Preserve the migrated MRN sequence high-water mark.
- Correct order ID formatting and ECG graph behavior.
- Harden GDT controller lifecycle, ownership, and security boundaries.
